Spotify Clone
This project is a Spotify Clone built using HTML, CSS, and JavaScript. The app mimics some of the basic functionalities of Spotify, including browsing songs, playing music, pausing/resuming playback, and navigating through the playlist. It also incorporates a dynamic song list fetched from a local server or directory.

Features
Song Listing: The app fetches a list of available songs from a specified folder and displays them in an interactive list.
Song Playback: Users can play songs by clicking on the song title, with a custom audio player built using JavaScript.
Play/Pause: The app allows users to play and pause music through a dedicated play/pause button.
Seekbar: A clickable progress bar allows users to seek through the current song.
Previous/Next Buttons: Users can navigate to the previous or next song in the playlist.
Music Information: Displays the song title and artist name while the song is playing.
Responsive Design: The app has a mobile-friendly design, making it accessible on various screen sizes.
Technologies Used
HTML5: For structuring the web pages.
CSS3: For styling and responsive design.
JavaScript: For dynamic functionality (e.g., fetching song lists, controlling playback).
Audio API: For handling audio playback, seeking, and time updates.
Setup Instructions
Clone this repository to your local machine.
Make sure you have a web server running locally (e.g., using Live Server in VSCode or a similar tool).
Place your music files (in .mp3 format) in the Audio folder.
Open index.html in your browser to start the Spotify Clone app.
